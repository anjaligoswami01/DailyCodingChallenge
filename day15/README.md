# 📊 Text Embedding Operations using NumPy

## 📌 Overview
This project demonstrates how to use **NumPy** for efficient vectorized operations on text embeddings, a key concept in Natural Language Processing (NLP).

## 🚀 Features
- Vectorized normalization of embeddings  
- Cosine similarity computation  
- Mean embedding (sentence representation)  
- Element-wise scaling operations  

## 🛠️ Tech Stack
- Python  
- NumPy
